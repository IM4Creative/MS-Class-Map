# Makerspace Class Map

Every Yazaki Makerspace class on one transit-style map. Each skill area is a line and each class is a stop. Orientation is where every line starts.

- Full page: https://im4creative.github.io/MS-Class-Map/
- Embed view for the SharePoint Classes page: https://im4creative.github.io/MS-Class-Map/?embed

Tap a stop to see what you'll learn and what it unlocks, then book a seat in Microsoft Bookings (Yazaki sign-in required). "I've taken this" ticks are saved only in your own browser.

The class data is in the `CL` and `LINES` arrays at the top of the script in `index.html`.
